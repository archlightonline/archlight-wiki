Stat Node Overview

Power nodes that add stats or cap-related bonuses

Stat Nodes are represented through Talent Tree node bonuses and related stat bonuses from Soul Shards. The available patch-note source lists node costs from 1 to 5 points, with higher-cost nodes giving stronger or more specialized bonuses.
