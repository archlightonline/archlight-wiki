Awakening Overview

Post-level progression

Awakening is a core character progression layer used by many Archlight systems. Quest access, prestige timing, spell progression, and several late-game activities reference Awakening levels.

500

Prestige Start

Prestige begins at Awakening 500 in the old guide content, while newer progression notes place prestige into an optional 500-level milestone flow.

Where Awakening Matters

System gates and build planning
